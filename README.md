# 核查工作台 v19.15

本地 Word 文档核查与修订工作台。公开版保留完整通用源码、Web UI、启动脚本和自动化测试，不包含任何真实业务文档、运行输出、日志或旧 Git 历史。

## 主要能力

来源文档与目标文档按章节和内容角色匹配；可自动处理事项直接生成修订，不确定事项进入人工核对；支持整表替换、Word/WPS 结构与样式保持、修订语义以及导出前独立审计。

## 运行

运行时仅使用 Python 标准库。macOS 双击 `启动核查工作台.command`，Windows 使用 `启动核查工作台.bat`，或执行：

```bash
python start.py
```

## 测试

```bash
pip install -r requirements-dev.txt
python -m pytest -q
```

不要把真实 Word、PDF、Excel、导出结果或日志提交到仓库。运行数据目录已经由 `.gitignore` 排除。
